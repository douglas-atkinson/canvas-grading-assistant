# Cars, Engines, and Steering — Grading Assets

This directory contains instructor-controlled resources used to build a
grading-suggestion request.

## Contents

- `assignment_spec.md` — corrected and rubric-aligned assignment specification
- `rubric.json` — structured 200-point rubric with stable criterion IDs
- `instructor_notes.md` — grading philosophy and interpretation guidance
- `package_config.json` — paths, authority order, and package metadata
- `instructor_reference/` — normalized, comment-free reference implementation
- `supporting_files/car_data.csv` — actual assignment data file
- `starter_files/` — documents that were provided to students

## Important

The reference implementation is not the only correct solution. It is included
as one validated example and has lower authority than the rubric, assignment
specification, and instructor notes.
